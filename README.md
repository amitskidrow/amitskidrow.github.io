# ssdrive-laptop public information

Static application homepage and privacy policy for personal Google Drive transfer
and encrypted recovery tools. This repository contains website content only.

- Homepage: https://amitskidrow.github.io/
- Privacy policy: https://amitskidrow.github.io/privacy/
- Maintainer: https://github.com/amitskidrow

GitHub Pages publishes the `main` branch from the repository root. `.nojekyll`
keeps the HTML and CSS as static files; there is no custom build workflow,
application server, sign-in form, analytics or external font dependency.

Google OAuth branding uses `amitskidrow.github.io` as its authorized domain.
Publishing this website does not, by itself, complete Google app publishing,
domain verification, account consent or local credential configuration.

Credential JSON, OAuth tokens, encryption keys, media and private application
source do not belong in this repository. Contact questions can be raised in
the issue tracker without including private data.
